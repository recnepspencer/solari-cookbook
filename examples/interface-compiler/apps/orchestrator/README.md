# Orchestrator

The orchestrator is WORTH's delegated external-effect worker. It reads an active replay, runs private Solari actions, publishes observed facts, and settles the WORTH-admitted execution. It does not own capability, replay, evidence, or lifecycle state.

Lost recovery responses are reconciled through WORTH before any further business replay. The in-memory executor retains only the pending request identity and failed replay identity; WORTH's current lifecycle pointer selects the broken, verifying, or active implementation. Recovery reads and mutation responses must contain a matching capability/replay pair from the same query basis. Cancellation and timeout preserve typed effect posture; an uncertain effect is not permission to rewrite the UI workflow.

The demo's public tool is `trades.ingestIncomingTrade({ messageId })`. Its binding delegates directly to the generic semantic capability executor: read WORTH's contract, application, and active replay; admit execution through WORTH; run private Solari actions; verify the typed receipt; and settle the exact output through WORTH. There is no canned or parallel ingestion path.

Replay failures pass through a conservative diagnosis gate so outages and interaction/provider incidents do not masquerade as UI drift. Semantic drift requires a Solari session receipt retained by WORTH against the active replay; verifier-supplied references are not trusted, and cleanup uncertainty cannot degrade the API. After confirmed drift, Gemini explores through Solari and only successfully executed semantic actions are compiled into a WORTH candidate. WORTH admits the candidate before verification, records every fresh-session receipt, and either activates it after three successes or marks a failed candidate broken and authorizes another deadline-governed discovery cycle. Interrupted candidate verification resumes from WORTH's current projection on the next semantic call. Run `npm test --workspace @interface-compiler/orchestrator` for focused contract-publication, precondition, failure-classification, discovery-boundary, and runtime tests. `npm run demo:enron:recovery` is the live Solari/Gemini/WORTH recovery drill.
